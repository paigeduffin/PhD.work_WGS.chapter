# Genomic separation of Salish Sea and Pacific outer coast populations of the keystone sea star *Pisaster ochraceus*

Code associated with the manuscript by Paige J. Duffin, Lauren M. Schiebelhut, Michael N. Dawson, and John P. Wares.

## Data availability

Sequence data are available through NCBI SRA under BioProject PRJNA1117092. Associated data are available through NSF BCO-DMO (DOI: 10.26008/1912/bco-dmo.934772.1).
